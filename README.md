# PUYO LAB — ぷよぷよ練習室

個人のローカル環境で使う、日本語のぷよぷよシミュレーターと練習ドリルです。React / TypeScript / Vite。サーバーやアカウント登録は不要です。

## 起動

Node.js 22.12以上（開発確認は24）を使用します。

```sh
npm install
npm run dev
```

ターミナルに表示される `http://127.0.0.1:5173/` を開きます。使用中の場合は次の空きポートが選ばれます。ホストはローカルマシンに限定しています。

## できること

- 6列×12段＋非表示13段目の操作、左右回転、基本の壁・床補正、ちぎり、連鎖アニメーション。
- 消去得点、連鎖ごとの消去ログ、着地点表示、NEXT 2手、自動落下の切替。
- 1手戻す、同じ配ぷよでリセット、盤面編集、編集した盤面だけの連鎖再生、現在の組ぷよの色変更。
- 盤面・配ぷよをJSON保存／読込。PCキーボードとタッチボタンに対応。
- **中級・上級向けの次の一手72問・15テーマ**。初歩の消去・用語クイズは収録しません。
- 構築問題64問：1〜3手のツモを置き、確認ツモから目標連鎖に接続。雪崩、潜り込み・斉藤SP、同色連鎖、クッション、底上げ、多重折り、後折り、逆発火など。
- 催促問題8問：2〜3連鎖の攻撃火力と、攻撃後に残る本線を両方採点。
- 8問は「ちぎり0回」の追加条件つき。全72問中、52問が複数手です。
- 形の一致でなく消去・連鎖数・火力・残し・ちぎりの条件を判定し、別解も正解にします。
- 現在のツモ・NEXT・確認ツモを表示。ヒント、具体的な配置手順、消去順、誤答理由、回答と解答例のコマ送り／自動再生。
- テーマ・難易度・手数・キーワード・誤答履歴で絞り込み。盤面プレビューから問題を選べます。
- 正答率、クリア数、連続学習日数、7日間の履歴、記録のダウンロード。解答例の閲覧では回答記録を増やしません。
- 8つの攻略サイト・21記事と公式素材の出典、8つの中上級向け学習ノート。旧入門問題の記録は現在の達成率に含めません。

構築問題は完成形を発火するだけの問題ではなく、不足する接続を配ぷよで補います。確認ツモは構築後の仮想ツモです。その全到達可能配置を探索して、最も長い連鎖を採点します。実戦の未知ツモ・相手盤面・時間制限を含む最善手判定ではありません。

### 操作

| キー            | 動作                                  |
| --------------- | ------------------------------------- |
| ← / →           | 1マス移動（長押しはOSのキーリピート） |
| Z / X、または ↑ | 左回転 / 右回転                       |
| ↓               | 1マス落下（フリーでは接地時に確定）   |
| Space           | 即設置（練習専用機能）                |
| U               | フリーシミュレーターで1手戻す         |

フリーの自動落下は初期状態でOFF、ドリルは思考練習のため自動落下しません。NEXTドリルの入力数は成立した移動・回転・下入力を数え、確定を含みません。フリーの入力数には失敗した入力も含みます。いずれも実機のフレーム数ではありません。

## シミュレーションの範囲

- 上下左右の同色4個以上で消去。斜めはつながりません。
- 13段目は消去判定に含めず、消去後の落下には含めます。3列12段目が塞がるとゲームオーバーです。
- 通ルールに基づく消去得点（連鎖・各連結・同時消去色数ボーナス）。倍率の最低値1・最高値999。
- おじゃまの表示は消去得点を70で割った単独の目安です。落下ボーナス、全消しボーナスの持ち越し、余剰点、相殺、マージン、実際のおじゃま攻撃は実装していません。
- 回転は基本の壁・床補正です。クイックターン、先行入力、DAS、ロック遅延、製品・機種ごとのフレーム精度の完全再現ではありません。
- 操作の最短手順は本シミュレーターの離散入力モデルに限ります。実機での最速手順とは異なります。
- 自由な局面のAI評価・オンライン対戦・相手AIはありません。配置ドリルは明示した達成条件で採点します。
- 構築盤面は参照記事の連鎖形から、接続を抜き出して配ぷよを設定した派生課題です。元記事の画像・文章は収録しません。出典・加工内容は各問題と [調査記録](docs/RESEARCH.md) に記載しています。

学習記録と任意の画像は `localStorage` に保存します。記録は最新2,000回答までです。サーバー送信・同期は行いません。フォントも同梱し、通常のプレイに外部通信は不要です。

## 開発・検証

```sh
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:e2e
```

ユニットテスト97件で消去・得点・隠し段・おじゃま・回転・ちぎり・72問の解答可能性・別解・暴発・催促後の残しを検証。E2Eは実際のキーボード／タッチ回答、誤答復習、正解再生、巻戻し、編集、JSON入出力、記録永続化、画面遷移、レスポンシブ表示を検証します。

Playwrightのブラウザライブラリをシステムに入れられない環境では、Ubuntuの `libnspr4` / `libnss3` / `libasound2t64` を一時ディレクトリに展開し、`LD_LIBRARY_PATH` を設定する方法でも検証できます。アプリ起動には不要です。

## 問題集の再生成

`scripts/research/motifs.json` に参照した連鎖形の数値データと出典を記録し、`src/data/next-drills.json` に配ぷよ・解答経路・条件を固定保存しています。実行時に外部サイトへアクセスしたり問題をランダム生成したりしません。

```sh
node scripts/generate-drills.mjs
npm test
```

再生成スクリプトはNode.js 24のTypeScript型除去を利用します。左右反転・色替えによる問題の増量は行いません。完成形から戻せる上面の組ぷよを抜き、構築前の確認ツモだけでは目標連鎖に届かないことを検査します。
