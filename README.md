# PUYO LAB — ぷよぷよ練習室

ブラウザで使う、日本語のぷよぷよシミュレーターと練習ドリルです。React / TypeScript / Vite。GitHub Pagesでの公開とローカル利用に対応し、バックエンドやアカウント登録は不要です。

## 起動

Node.js 22.12以上（開発確認は24）を使用します。

```sh
npm install
npm run dev
```

ターミナルに表示される `http://127.0.0.1:5173/` を開きます。使用中の場合は次の空きポートが選ばれます。ホストはローカルマシンに限定しています。

## GitHub Pagesで公開する

公開先は `https://ikkungames110.github.io/puyopuyo/` です。リポジトリの所有者がGitHub上で以下を実行します。

1. リポジトリの **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選択します。
2. **Actions → Deploy to GitHub Pages → Run workflow** から **main** を選んで実行します。
3. ワークフローが完了したら、表示された公開URLを開きます。

以降の更新も同じワークフローを手動実行します。pushだけでは公開されません。ワークフローは依存関係のインストール、ユニットテスト、公開用ビルド、公開用E2Eテストを実行してから、`dist/` を配信します。設定方法は [GitHubの公式ドキュメント](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages) を参照してください。

公開前にローカルで確認する場合：

```sh
npm ci
npm run build:pages
npm run preview:pages
```

`http://127.0.0.1:4173/puyopuyo/` を開きます。公開用ビルドは `/puyopuyo/` を基準にJS・CSS・フォントを読み込みます。リポジトリ名や独自ドメインを変更する場合は、`vite.config.ts` の `base` と公開用テストのURLも更新してください（[Viteの公式ガイド](https://vite.dev/guide/static-deploy.html#github-pages)）。

公開用ビルドは公式ぷよ画像を使用します。`npm run build:pages` が固定コミットの素材を取得してSHA-256を検証し、画像・付属利用許諾書・フォントのライセンスを同梱します。調査用動画・字幕・フレームも公開物には含まれません。学習記録・表示設定は各ブラウザ内に保存され、ローカル版の記録は公開先へ自動移行されません。

## できること

- **ゲームパッド対応**。USB / Bluetoothの十字キー・左スティックで移動、左右回転、下入力、即設置、巻き戻し、ドリルの答え合わせ。
- キーボードとゲームパッドで共通の長押し移動（DAS / ARR）、スティックの遊び、ボタン割り当てを調整・保存。複数接続時の機器選択と押したボタン番号の表示。
- **自由落下なし**。下を押している間だけ落下し、接地後250msで確定。下を離せば接地中でも停止。即設置も利用可能。
- 6列×12段＋非表示13段目、壁・床補正、両側が塞がったときの回転2度押しによるクイックターン、ちぎり、連鎖アニメーション。
- NEXT 2手、消去得点とログ、着地点表示、1手戻す、同じ配ぷよでリセット、盤面編集、JSON保存・読込。
- **417問・54テーマ**。構築388問、催促8問、判断21問。配置問題は165種類の元図から作成。1〜4手で接続を補い、確認ツモから3〜16連鎖を作る。75問はちぎり0回の条件つき。
- GTR、新GTR、底上げGTR、なめくじ、座布団L字、後折り、第二折り返し、多重（座布団・L字・複合）、雪崩、鶴亀・潜り込み、同色連鎖、クッション、余りぷよの回収など。
- **34件の学習ノート**。分野とキーワードで検索。チェックポイント・典型的な失敗・盤面の消去順・関連問題・自由編集への導線。
- 登録手順との一致でなく、連鎖数・火力・残し・暴発・ちぎりの条件で採点。別解も正解。自分の回答と解答例をコマ送りで比較。
- **YouTubeの30検索候補を比較し、6本・約130分の動画を取得して調査**。日本語自動字幕と要所のフレームを照合。30記事と6動画の出典・動画の該当時刻を表示。
- 正答率、クリア数、誤答復習、7日間の履歴、学習記録のダウンロード。通常のプレイに外部通信は不要。

配置問題396問のうち301問が複数手です。既存の拡張280問と記事追加の配置35問は、色替え・左右反転を同じ構造として判定して重複を除外しています。同じ元図から異なる不足箇所・手数を設定した課題は共通の元図IDを保持します。

構築後の「確認ツモ」は仮想の後続ツモです。全到達可能配置から最長連鎖を探索して接続を採点します。未知の実戦ツモや相手盤面まで含む最善手の判定ではありません。

### 操作

| 入力                                     | 動作                                        |
| ---------------------------------------- | ------------------------------------------- |
| ← / →、十字キー左右、左スティック左右    | 移動。長押しは150ms後から45ms間隔（調整可） |
| Z / X、または ↑                          | 左回転 / 右回転（↑はキーボードのみ）        |
| 標準パッドの下側 / 右側ボタン（B0 / B1） | 左回転 / 右回転                             |
| ↓、十字キー下、スティック下              | 手動落下。接地後も押し続けると250msで確定   |
| Space、十字キー上（B12）、左スティック上、上側ボタン（B3） | ハードドロップ（即設置） |
| U、L / LB（B4）                          | 1手戻す                                     |
| Enter、Start / Options（B9）             | ドリルの答え合わせ                          |

パッドを接続したらボタンを一度押してブラウザへ認識させ、離してから操作してください。機種名ではなくブラウザの標準配置を使用します。Nintendo系を含め表示名と割り当てが合わない場合は、盤面下の「コントローラー・操作設定」でボタン番号を見ながら変更できます。標準配列以外の機器も個別設定できます。十字キー上（B12）と左スティック上はハードドロップです。保存済みのボタン設定があっても使用でき、長押しでは次のツモを連続設置しません。キーボードの↑は右回転のままです。

設定欄・テキスト入力中、ウィンドウ非アクティブ時は入力を停止します。切断・再接続・画面切替時の押しっぱなしによる誤操作を避けるため、パッドは一度中立に戻してから受け付けます。Gamepad APIはlocalhostまたはHTTPSで使用してください。

自動落下のスイッチはありません。消去後の重力と横置き時のちぎりは連鎖のルールとして適用します。クイックターンは両側が塞がった縦ぷよに同じ回転を300ms以内に2回入力すると上下を入れ替えます。問題の解答探索では時間を持たない離散入力として扱います。

## 盤面とツモから最善の置き方を考える

[「多重折りは三種類しかない」](https://note.com/saikyo3018/n/n951e68d4fdb9) をもとに、**1〜2手の配置問題を9問**追加しました。ハンバーガー型、カギ積み型、クッション型、卍型の底上げを扱います。練習ドリルの `#記事n951e68d4fdb9` または `#最善手` から遊べます。

盤面と表示ツモを見て実際に置き、暴発せずに接続確認ツモから最大連鎖へつなげる問題です。全合法配置を探索して最大値（6〜9連鎖）を検証し、同じ最大値に届く別解も正解にします。解答後は自分の配置と解答例を再生できます。未知のツモや対戦状況を含めた最善手ではありません。[出典・加工・採点基準](docs/NOTE-FOLD.md) を参照してください。

## 記事の問題とタグ検索

[ちぇすな「GTRの連鎖尾の組み方(主に雪崩系)」](https://puyo-camp.jp/posts/104662) の全節を、配置35問・判断21問にまとめています。原因、段差、Y字下ゾロ／下二色、だぁ積み、色配分、鶴亀、仕込みを扱います。本文の説明画像47枚（スライド内の小図を含め51盤面）を数値化し、各図に対応する問題を用意しました。画像そのものや記事の全文は配信しません。

練習ドリルの検索欄で `#記事104662` または `#ちぇすな` を入力すると全56問が表示されます。`#Y字下ゾロ`、`#雪崩`、`#鶴亀`、`#仕込み` などでも検索できます。`#記事104662 #仕込み 判断` のようにスペースで区切るとAND検索です。全角の＃・英数字、大文字小文字にも対応します。画面上のタグボタンを押して絞り込むこともできます。

判断問題は図を切り替えて比較し、選択肢で回答します。配置問題と共通で成績・クリア・誤答復習を保存します。[各節・図との対応表](docs/CAMP-104662.md) を参照してください。

## 動画の調査と教材化

[調査記録](docs/RESEARCH.md) に候補の選び方、再生数、該当時刻、盤面の加工内容、各テーマの問題数をまとめています。元動画を全編実時間で通し視聴したという意味ではなく、字幕による内容抽出と要所の画像確認による調査です。

- `research-local/videos/`：取得した6本の映像、日本語字幕、字幕テキスト、取得メタデータ。
- `research-local/frames/`：分析箇所の確認用フレーム。
- `scripts/research/video-search.json`：検索候補30件と調査時点の再生数。
- `src/data/research-videos.json`：採用動画の出典、時刻別の分析、取得ファイルのSHA-256。
- `scripts/research/expanded-motifs.json`：記事の数値盤面・動画の転記盤面と加工の記録。

原動画・字幕・フレームはGit管理外のローカル調査資料です。サイトから動画リンクを開くとYouTubeへ移動します。動画本体のアプリ内配信は行いません。

再検索・再取得用の補助スクリプトも用意しています。`yt-dlp`、Node.js、フレーム抽出には`ffmpeg`を使用します。

```sh
python3 scripts/research-videos.py --help
python3 scripts/research-videos.py --discover --download --frames
```

この作業環境に保存したツールを使う場合：

```sh
python3 scripts/research-videos.py --frames \
  --ffmpeg research-local/tools/ffmpeg-7.0.2-amd64-static/ffmpeg
python3 scripts/research-videos.py --discover --download \
  --yt-dlp research-local/tools/yt-dlp
```

## 公式画像

個人の練習用として、ローカル版とGitHub Pages版の両方で公式素材を使います。`public/official/` に「ぷよぷよプログラミング」由来の5色＋おじゃまの画像と、付属の利用許諾書を配置しています。**©SEGA**。画像は改変していません。

公式紹介元は [SEGA ぷよぷよプログラミング](https://puyo.sega.jp/program_2020/)、教材窓口は [Monaca Education](https://edu.monaca.io/puyo1) です。取得経路は教材を収録した [sity-games/sega-puyo](https://github.com/sity-games/sega-puyo) の固定コミットです。SEGAのサーバーから直接取得したものではありません。ファイルごとのSHA-256と取得元を `scripts/asset-provenance.json` に記録しています。サンプルのゲームソースは取り込んでいません。

画像はGit管理対象外です。公開用ビルドでは自動取得します。ローカル開発用に必要な場合は以下で取得します。

```sh
npm run assets:install
```

教材に付属する利用条件は `public/official/SEGA_License.txt` に保存し、アプリの「参考資料・クレジット」からも開けます。GitHub Pagesでは素材取得とサブパス設定を含む **`npm run build:pages`** を使用してください。

公式画像が配置されていない環境ではアプリ内の仮イラストにフォールバックします。「表示設定」から色ごとの画像をこのブラウザ内に設定することもできます。

## シミュレーションの範囲

- 上下左右の同色4個以上で消去。斜めはつながりません。
- 13段目は消去判定に含めず、消去後の落下には含めます。3列12段目が塞がるとゲームオーバーです。
- 通ルールに基づく消去得点（連鎖・各連結・同時消去色数ボーナス）。倍率の最低値1・最高値999。
- おじゃまの表示は消去得点を70で割った単独の目安です。落下ボーナス、全消しボーナスの持ち越し、余剰点、相殺、マージン、実際のおじゃま攻撃は実装していません。
- 回転は基本の壁・床補正とクイックターンです。DAS / ARRと手動落下時の接地遅延を実装しています。先行入力や製品・機種ごとのフレーム精度の完全再現ではありません。
- 操作の最短手順は本シミュレーターの離散入力モデルに限ります。実機での最速手順とは異なります。
- 自由な局面のAI評価・オンライン対戦・相手AIはありません。配置ドリルは明示した達成条件で採点します。
- 構築盤面は参照記事・動画の連鎖形から、接続を抜き出して配ぷよを設定した派生課題です。元記事の画像・文章は収録しません。出典・加工内容は各問題と [調査記録](docs/RESEARCH.md) に記載しています。

学習記録と任意の画像は `localStorage` に保存します。記録は最新2,000回答までです。サーバー送信・同期は行いません。フォントも同梱し、通常のプレイに外部通信は不要です。

## 開発・検証

```sh
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:e2e
npm run build:pages
npm run test:pages
```

ユニットテストで配置問題396問の合法な解答・別解・暴発・催促後の残し・色替えや反転の重複除外・入力リピート・クイックターンを検証。E2EではGamepad APIの模擬入力、キーボード／タッチ、落下停止、接地確定、設定保存、切断・復帰、教材から自由練習への移行、スマホ表示まで検証します。物理コントローラーを接続しての実機テストは、この環境では未実施です。

Playwrightのブラウザライブラリをシステムに入れられない環境では、Ubuntuの `libnspr4` / `libnss3` / `libasound2t64` を一時ディレクトリに展開し、`LD_LIBRARY_PATH` を設定する方法でも検証できます。アプリ起動には不要です。

## 問題集の再生成

`scripts/research/motifs.json` と `scripts/research/expanded-motifs.json` に参照した連鎖形の数値データと出典を記録し、`src/data/next-drills.json` に配ぷよ・解答経路・条件を固定保存しています。実行時に外部サイトへアクセスしたり問題をランダム生成したりしません。

```sh
node scripts/generate-drills.mjs
node scripts/generate-camp-drills.mjs
node scripts/generate-note-drills.mjs
npm test
```

再生成スクリプトはNode.js 24のTypeScript型除去を利用します。新規構築問題は左右反転・色替えも同一構造として重複を除外します。完成形から戻せる上面の組ぷよを抜き、構築前の確認ツモだけでは目標連鎖に届かないことを検査します。
