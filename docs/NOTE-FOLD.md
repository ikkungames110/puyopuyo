# GTR上を、ツモからどう伸ばすか判断する

出典：[みらいやまさると最強の生活「【ぷよぷよ】多重折りは三種類しかない」](https://note.com/saikyo3018/n/n951e68d4fdb9)（2025-05-26）。

## 練習する判断

GTRの上がまだ3〜4段目までしかない盤面と、CURRENT・NEXT 2手を提示します。自分で方針を選び、回答後に各候補を比較します。完成形からぷよを抜いた問題ではありません。題名・タグには正解となる型を表示しません。確認ツモや目標連鎖数も設定しません。

記事の考え方を参考に、「座布団」「クッション・卍型Aの受け」「カギ積み・卍型Bの候補」「保留」のどれを優先するかを問います。記事の優先順位を使うため、実戦の唯一の最適解を数学的に保証するものではありません。方針を選ぶクイズであり、配置操作の採点は行いません。

回答後には、推奨理由だけでなく、別の候補が可能か、色の数や位置にどんな制約があるかを表示します。完成形を固定せず、後続のツモに応じて伸ばせる組み始めの例をコマ送りで確認できます。

## 問題の対比

| ID  | 同じ条件と変える条件                            | 推奨方針                |
| --- | ----------------------------------------------- | ----------------------- |
| a1  | 初期GTR、緑青 → 赤青 → 緑黄                     | クッション・卍型Aの受け |
| a2  | a1と同じ盤面・CURRENT、緑青 → 緑赤 → 緑黄       | 座布団                  |
| a3  | a1と同じ盤面・CURRENT、緑青 → 赤青 → 黄黄       | カギ積み・卍型Bの候補   |
| a4  | 初期GTR、赤青 → 赤青 → 黄黄                     | 保留                    |
| b1  | 3列側に緑1個、青黄 → 赤青 → 黄黄                | カギ積み・卍型Bの候補   |
| b2  | b1と同じ盤面・CURRENT、青黄 → 緑赤 → 黄青       | クッション・卍型Aの受け |
| b3  | b1と同じ盤面・CURRENT、青黄 → 緑緑 → 赤青       | 座布団                  |
| c1  | b2と同じツモ・緑の個数、既存の緑だけ1列側へ変更 | 保留                    |
| c2  | c1と同じ盤面・CURRENT、青黄 → 緑赤 → 緑青       | 座布団                  |

IDの接頭辞は `foundation-`。特にb2とc1は、単に緑を数えるだけでは判断できない比較です。「ツモ違いを解く」で同じ盤面の別問を開けます。

## 配置例の検証範囲

GTR左3列の配色を基本に、右側は簡略化した独自の土台を設定しています。画像の省略記号をおじゃまぷよに置換することはしません。

生成時に、表示3手を置く全到達可能配置を調べます。暴発やゲームオーバーになる配置を除き、4段目に緑の横3を作れるか、2・3列に置けるか、3列側の1個を受けにできるかを比較します。候補の優先順位は教材のルールです。探索は候補の実現可能性と配置例の合法性を確認するために使い、将来のツモ・相手・実戦的な期待値を採点するものではありません。

推奨方針は各問題に手で指定し、探索結果が想定と異なる場合は生成を止めます。異なる経路の盤面を比較し、低く、ちぎりを抑えた配置例を選びます。例の先には未完成部分が残ります。

```sh
node scripts/generate-foundation-drills.mjs
npm test
```

Node.js 24で実行します。問題定義は `scripts/generate-foundation-drills.mjs`、出力は `src/data/foundation-drills.json`。ユニットテストでツモ・位置による方針の変化、例の合法性、GTRの維持を確認します。E2Eでは回答前に解説を見せないこと、回答・候補比較・ツモ違いへの移動・学習記録・スマホ表示を検証します。
