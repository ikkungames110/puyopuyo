# 実装メモ

- `src/engine.ts`: UIと独立した盤面演算。下から上に13行、各行6列。0=空、1=赤、2=緑、3=青、4=黄、5=紫、6=おじゃま。`placements` が移動・回転・下入力の幅優先探索で到達可能な着地を列挙する。
- `src/data/next-drills.json`: 中上級の配置問題352問。構築344問、催促8問。うち75問はちぎり制約。問題ごとの盤面・1〜4手の配ぷよ・確認ツモ・解答経路・目標・出典を固定保存。
- `src/content.ts`: 問題の型、32テーマ、出典36件（攻略29記事＋動画6本＋素材1件）、34件の学習ノート。旧配置問題の型・判定関数はフリーシミュレーターと互換性を保つため残している。現在の問題集に入門問題や選択クイズは含まない。
- `src/sequence.ts`: 複数手の採点と再生。構築途中の消去を禁止。催促は最終手の2〜3連鎖・最低得点を判定。確認ツモの全到達可能配置から最大連鎖を選び、構築の接続／催促後の本線を検証。登録手順との座標一致は要求せず、条件を満たす別解を許可。
- `src/NextTrainer.tsx`: ツモを実操作して配置し、全手の後に明示的に採点。現在・NEXT・NEXT2・仮想の確認ツモを区別して表示。各手の配置、各消去、最後の残りをコマ送り／自動再生し、自分の回答と解答例を切替。解答例の閲覧は成績に記録しない。再生タイマーは終了・リセット・アンマウント時に破棄。
- `src/Simulator.tsx`: フリー操作・連鎖アニメーション・編集・JSON入出力。古い連鎖再生を世代番号でキャンセル。盤面＋配ぷよインデックス＋得点を履歴として保持。
- `src/controls.ts`: 入力のエッジ検出とDAS / ARR。左右同時入力を中立化し、回転・設置・戻すは一度押すごとに一回。設定の保存値を検証して範囲制限。
- `src/useGameControls.ts`: キーボードとGamepad APIの共通入力。requestAnimationFrameでポーリングし、切断・blur・visibilitychange・設定フォーム入力中に解除。復帰時はパッドの中立を要求。同一フレームの複数入力はflushSyncで移動や回転を確定してから次へ渡す。
- `src/ControllerPanel.tsx`: 機器選択、ボタンモニター、8動作の割当、長押し速度とデッドゾーン設定。同じボタンの二重割当は解除する。
- `src/StudyLibrary.tsx`: 分野・検索によるノート表示。対応する問題の完成形をエンジンで再構成し、消去順のコマ送り、問題への移行、種を自由練習へコピー。動画は外部リンクのみ。
- `src/Board.tsx`: 盤面、着地点、消去対象。
- `src/storage.ts`: 保存形式の検証、ローカル日付による履歴・継続日数。`App` の読込時に現在の問題集にない旧IDを集計対象から除外。
- `src/Puyo.tsx`: ローカル公式画像・ブラウザ内の任意画像・仮イラスト。読込失敗は仮イラストへ戻る。
- `src/App.tsx`: 画面遷移、テーマ／難易度／手数／検索／誤答フィルター、盤面プレビュー、履歴、資料、素材設定。
- `scripts/research/motifs.json`: 出典の完成形を数値として転記した作問用資料。既存の画像ファイルを同梱しない。原形・出典・どの図かを保持。
- `scripts/research/expanded-motifs.json`: 今回追加した記事のシミュレーター盤面と動画の手動転記・派生形。元動画の時刻と補完したキーを明記。
- `scripts/research-videos.py`: 3テーマの検索、採用動画の取得、日本語字幕の整形、分析時刻付近のフレーム抽出。結果はGit管理外のresearch-localへ。
- `scripts/generate-drills.mjs`: Node.js 24用のオフライン作問スクリプト。安定した種から上面の組ぷよを1〜4手抜き、逆順に合法操作で復元できることを検査。構築前や復元途中に確認ツモだけで目標達成できる候補を除外。催促は短い攻撃後の接続も探索。新規盤面は色替え・左右反転の正規化によって既存盤面との重複を除外。採用できなかった元図の理由をgeneration-report.jsonに出力。乱数は固定seedで、ブラウザ内では再生成しない。
- `scripts/install-assets.mjs`: 固定コミットから素材を取得してSHA-256を検証。画像とライセンスはGit管理外の `public/official/` に配置。

## 操作と時間

自由落下のタイマーを持たない。下入力でのみ一段ずつ移動し、接地中の下入力が250ms続くと設置する。下を離す、盤面を戻す、リセットする、設置する際に接地時間を解除する。消去アニメーションは自由落下とは独立している。

`Piece.quick`は両側が塞がった縦ぷよの回転待ち状態。再度同じ方向に回転すると位置を入れ替える。UIは300ms以内の二度押しを要求する。探索側は離散入力として待ち状態も訪問キーへ含めるため、二度押しでしか到達できない配置も列挙できる。製品ごとの先行入力や厳密なフレーム再現は対象外。

## 判定上の境界

「確認ツモ」は構築手に含めず、将来その色が来た場合の接続テストとして使う。確認ツモの置き方をプレイヤーに要求しない。各問題の目標は条件達成であり、未知の配ぷよや相手盤面を含む一般的な最善手を意味しない。ちぎり回数は横置き2個の着地段数が異なる場合に加算。操作の入力数は実機フレーム数ではない。

## 盤面JSON v1

`{ "version": 1, "board": Color[13][6], "queue": [Color, Color][] }`

読込時に行列のサイズ、色の整数範囲、配ぷよが1〜5色か、長さ1〜1000かを検証する。浮いているセルは重力で詰める。操作中の組ぷよは盤面に含まず、queue先頭に保存する。
