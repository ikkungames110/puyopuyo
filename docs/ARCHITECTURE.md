# 実装メモ

- `src/engine.ts`: UIと独立した純粋関数。盤面は下から上に13行、各行6列。0=空、1=赤、2=緑、3=青、4=黄、5=紫、6=おじゃま。
- `src/content.ts`: 26問のドリル、明示ゴールによる採点、学習ノートと出典。配置の解答例は固定文字列ではなくエンジンの幅優先探索から生成。
- `src/Simulator.tsx`: 操作・再生・編集・JSON入出力。世代番号で古い連鎖アニメーションをキャンセル。盤面＋配ぷよインデックス＋得点を履歴として保持。
- `src/Board.tsx`: 盤面、着地点、消去対象、操作ドリルの目標位置。
- `src/storage.ts`: 保存形式の検証、ローカル日付での学習履歴、継続日数。
- `src/Puyo.tsx`: ローカルの画像、ブラウザ内で設定した画像、仮イラストの順に表示。読み込み失敗時は仮イラストへ戻る。
- `src/App.tsx`: 画面遷移、クイズ、履歴、資料、素材設定。学習記録は関数型更新で更新し、連鎖記録と回答記録の競合を避ける。
- `scripts/install-assets.mjs`: 固定コミットから素材を取得しSHA-256を検証。画像とライセンス原文はGit管理外の `public/official/` に配置。

## 盤面JSON v1

`{ "version": 1, "board": Color[13][6], "queue": [Color, Color][] }`

読込時に行列のサイズ、色の整数範囲、配ぷよが1〜5色か、長さ1〜1000かを検証する。盤面に浮いているセルは重力で詰める。プレイ中の組ぷよはまだ盤面には含まず、queue先頭に保存する。
