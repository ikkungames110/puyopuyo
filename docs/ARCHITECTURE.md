# 実装メモ

- `src/engine.ts`: UIと独立した盤面演算。下から上に13行、各行6列。0=空、1=赤、2=緑、3=青、4=黄、5=紫、6=おじゃま。`placements` が移動・回転・下入力の幅優先探索で到達可能な着地を列挙する。
- `src/data/next-drills.json`: 中上級の配置問題72問。構築64問、催促8問。うち8問はちぎり制約。問題ごとの盤面・1〜3手の配ぷよ・確認ツモ・解答経路・目標・出典を固定保存。
- `src/content.ts`: 問題の型、15テーマ、出典22件（攻略21記事＋素材1件）、8つの学習ノート。旧配置問題の型・判定関数はフリーシミュレーターと互換性を保つため残している。現在の問題集に入門問題や選択クイズは含まない。
- `src/sequence.ts`: 複数手の採点と再生。構築途中の消去を禁止。催促は最終手の2〜3連鎖・最低得点を判定。確認ツモの全到達可能配置から最大連鎖を選び、構築の接続／催促後の本線を検証。登録手順との座標一致は要求せず、条件を満たす別解を許可。
- `src/NextTrainer.tsx`: ツモを実操作して配置し、全手の後に明示的に採点。現在・NEXT・NEXT2・仮想の確認ツモを区別して表示。各手の配置、各消去、最後の残りをコマ送り／自動再生し、自分の回答と解答例を切替。解答例の閲覧は成績に記録しない。再生タイマーは終了・リセット・アンマウント時に破棄。
- `src/Simulator.tsx`: フリー操作・連鎖アニメーション・編集・JSON入出力。古い連鎖再生を世代番号でキャンセル。盤面＋配ぷよインデックス＋得点を履歴として保持。
- `src/Board.tsx`: 盤面、着地点、消去対象。
- `src/storage.ts`: 保存形式の検証、ローカル日付による履歴・継続日数。`App` の読込時に現在の問題集にない旧IDを集計対象から除外。
- `src/Puyo.tsx`: ローカル公式画像・ブラウザ内の任意画像・仮イラスト。読込失敗は仮イラストへ戻る。
- `src/App.tsx`: 画面遷移、テーマ／難易度／手数／検索／誤答フィルター、盤面プレビュー、履歴、資料、素材設定。
- `scripts/research/motifs.json`: 出典の完成形を数値として転記した作問用資料。既存の画像ファイルを同梱しない。原形・出典・どの図かを保持。
- `scripts/generate-drills.mjs`: Node.js 24用のオフライン作問スクリプト。安定した種から上面の組ぷよを1〜3手抜き、逆順に合法操作で復元できることを検査。構築前や復元途中に確認ツモだけで目標達成できる候補を除外。催促は短い攻撃後の接続も探索。乱数は固定seedで、ブラウザ内では再生成しない。
- `scripts/install-assets.mjs`: 固定コミットから素材を取得してSHA-256を検証。画像とライセンスはGit管理外の `public/official/` に配置。

## 判定上の境界

「確認ツモ」は構築手に含めず、将来その色が来た場合の接続テストとして使う。確認ツモの置き方をプレイヤーに要求しない。各問題の目標は条件達成であり、未知の配ぷよや相手盤面を含む一般的な最善手を意味しない。ちぎり回数は横置き2個の着地段数が異なる場合に加算。操作の入力数は実機フレーム数ではない。

## 盤面JSON v1

`{ "version": 1, "board": Color[13][6], "queue": [Color, Color][] }`

読込時に行列のサイズ、色の整数範囲、配ぷよが1〜5色か、長さ1〜1000かを検証する。浮いているセルは重力で詰める。操作中の組ぷよは盤面に含まず、queue先頭に保存する。
